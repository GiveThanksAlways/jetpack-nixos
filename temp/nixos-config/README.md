# Jetson NixOS Configuration

This directory contains your NixOS configuration for the Jetson Orin AGX.

## Files

- `flake.nix` - Flake entry point (imports jetpack-nixos)
- `configuration.nix` - Your system configuration
- `hardware-configuration.nix` - Auto-generated by `nixos-generate-config` (you create this on the Jetson)

## Installation Steps

### On the Jetson (booted from USB installer):

```bash
# 0. Become root
sudo -i

# 1. Partition the NVMe SSD
parted /dev/nvme0n1 -- mklabel gpt
parted /dev/nvme0n1 -- mkpart ESP fat32 1MB 512MB
parted /dev/nvme0n1 -- set 1 esp on
parted /dev/nvme0n1 -- mkpart root ext4 512MB -8GB
parted /dev/nvme0n1 -- mkpart swap linux-swap -8GB 100%

# 2. Format
mkfs.fat -F 32 -n boot /dev/nvme0n1p1
mkfs.ext4 -L nixos /dev/nvme0n1p2
mkswap -L swap /dev/nvme0n1p3

# 3. Mount
mount /dev/disk/by-label/nixos /mnt
mkdir -p /mnt/boot
mount -o umask=077 /dev/disk/by-label/boot /mnt/boot
swapon /dev/disk/by-label/swap

# 4. Generate hardware-configuration.nix
nixos-generate-config --root /mnt

# 5. Copy these config files to the Jetson
# Option A: If you have network, use curl/wget or git clone
# Option B: Copy via USB drive
# Option C: Type/paste them manually with nano

# Replace the auto-generated configuration.nix with this one:
nano /mnt/etc/nixos/configuration.nix
# (paste contents of configuration.nix)

# Create flake.nix:
nano /mnt/etc/nixos/flake.nix
# (paste contents of flake.nix)

# 6. Install
nixos-install --flake /mnt/etc/nixos#jetson

# 7. Set root password when prompted

# 8. Reboot
reboot
```

## Post-Installation

```bash
# Change your password!
passwd

# Future system updates:
sudo nixos-rebuild switch --flake /etc/nixos#jetson

# Update flake inputs (get latest jetpack-nixos):
cd /etc/nixos
sudo nix flake update
sudo nixos-rebuild switch --flake .#jetson
```

## Customization

### Using your fork of jetpack-nixos

Edit `flake.nix` and change:
```nix
jetpack-nixos.url = "github:YOUR_USERNAME/jetpack-nixos/your-branch";
```

### Adding more packages

Edit `configuration.nix` and add to `environment.systemPackages`.

### Enabling Docker with GPU

Uncomment the Docker section in `configuration.nix`.

## Determinate Nix Compatibility

The nix settings in `configuration.nix` mirror what Determinate Nix enables:
- Flakes enabled by default
- New `nix` command enabled
- Auto-optimization of store
- Garbage collection configured

On NixOS, you don't use the Determinate installer (NixOS has nix built-in).
Instead, we configure the same settings declaratively.
